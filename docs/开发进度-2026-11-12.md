## 2. 本轮已完成功能

### 日志查看

- Windows 日志列表直接显示事件 ID，不需要打开详情。
- 字段名中文化：支持 `System.*` / `EventData.*` 嵌套字段，例如：
  - `System.EventID` → 事件 ID
  - `System.Execution.ProcessID` → 进程 ID
  - `EventData.NormalProcessId` → 正常进程 ID
  - `EventData.TrustletIdentity` → 信任组件标识
  - `System.TimeCreated.SystemTime` → 系统时间
- EVTX `System={...} UserData={...}` 原始消息转换为中文摘要。
- 双击日志行展开“全部字段”；详情页字段表同样中文显示并保留原始键。
- 单条日志 AI 分析：仅本条 / 结合 ±5/±10/±20 条上下文，显示风险、摘要、发现、建议与相关 DocID。

### 日志页 AI 分析

- 新增“AI 分析”面板：日志类型（项目日志源）、时间范围、聚合分析 / 逐条分析。
- 逐条模式可加载候选日志，选择单条或上下文分析。
- 结果按项目持久化（`localStorage: glog.logs.ai.v1.<projectId>`），重新打开只恢复展示，不自动重跑。
