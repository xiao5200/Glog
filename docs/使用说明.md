# GLog 使用说明

## 1. 启动与数据目录

- 双击 `GLog.exe`（或开发模式 `wails dev`）。应用启动后停留在项目总览，不自动打开任何项目，初始界面不加载日志；打开项目后才进入日志工作台。
- 首次启动自动创建数据目录：
  - 优先：可执行文件旁 `data/`；
  - 不可写时：`%APPDATA%\GLog`；
  - 可用环境变量 `GLOG_DATA_DIR` 指定。
- 系统设置 → 通用可查看实际路径，并直接在文件管理器中打开。

> `data/secrets.key` 用于解密 SSH 密码与 AI API Key。迁移或备份数据目录时请一并保留。

## 2. 项目管理

| 操作 | 说明 |
|---|---|
| 新建 | 填写名称、描述、标签与优先级；创建后自动打开 |
| 打开 | 加载项目元数据与内存索引；同时只打开一个项目 |
| 归档 | 只读保留，可随时恢复（通过编辑状态） |
| 导出 | 生成 `.glogpkg.zip`，包含 project.meta、raw、indexes 与 SHA256 manifest |
| 导入 | 校验 manifest 后解压注册；同名项目 ID 会拒绝覆盖 |
| 删除 | 删除项目目录与数据库记录，不可恢复 |
| 本机日志发现 | 启动后自动扫描常见日志位置；“项目总览”仅显示数量摘要，完整列表在“数据采集”页；扫描结果仅为全局建议，不会自动加入任何项目 |
| 干净项目 | 新建项目默认 0 条日志、0 个来源；采集页任务队列只显示当前项目任务，切换项目会清空旧项目的来源、快照与采集预览 |

### 2.1 本机日志自动发现

- 应用启动时后台扫描当前主机常见日志路径（Windows 事件通道、`C:\Windows\Logs`、IIS/Nginx/Apache、ProgramData、用户目录；Linux `/var/log`、数据库与 audit、systemd journal）。
- 对文本文件读取少量样本，自动匹配解析模板并记录大小、可读性与预览。
- “项目总览 → 本机日志发现”展示数量摘要与**已发现日志路径列表**（类型、路径、大小、建议模板、可读状态）。
- 打开项目后可点击 **“一键获取本机日志”**：把所有可读发现项按类型/建议模板自动加入当前项目并启动采集任务，完成后可在“数据采集”页任务队列查看进度；重复点击会再次采集。
- 受保护事件通道（如 `Security`）可能需要管理员权限；EVTX 文件自动使用原生解析，受保护通道会自动尝试 `wevtutil` 导出。
- 在“数据采集 → 本地文件 → 启动时发现的本机日志”中仍可逐项选择路径并套用建议模板；可随时点击“重新扫描”更新结果。

## 3. 采集

### 3.1 本地文件

1. 在“数据采集 → 本地文件”填写路径，支持 `*` 通配符与多行；可点击“选择文件/目录”。
2. 常见路径、启动时发现的本机日志或中间件预设可一键填入（Nginx、MySQL、Apache、Docker 等）；`.evtx` 文件会自动按原生 EVTX 解析。
3. 选择递归、排除路径；`.gz` 自动解压。受保护的系统通道（如 `Setup`、`Security`）请在“Windows 事件日志”页采集，普通用户会自动通过 `wevtutil` 导出。
4. 解析配置：
   - **内置模板**：选择模板，或留空由格式检测自动选择；
   - **AI 模式**：选择已配置的 AI 提供商，样本数默认 40；可勾选保存生成的模板。
5. 点击“开始采集”，右侧任务队列显示进度；完成后日志源与项目统计自动刷新。
6. 本机采集的数据会自动登记为项目日志源。在右侧“日志源”中点击来源查看详情，可对其路径执行“再次采集”（本地/导入来源；EVTX 会使用原生解析），无需重新配置。

### 3.2 Windows 事件日志

- 勾选 System / Application / Security / Setup / Forwarded Events。
- 普通用户通常无法直接读取 `C:\Windows\System32\winevt\Logs\*.evtx`；应用会自动调用系统自带的 `wevtutil epl` 导出到临时目录后解析，完成任务后自动清理。
- `Security` 通道受 Windows 保护，仍需以管理员身份运行（或以管理员身份导出）。
- 可按时间范围、事件 ID、级别过滤；EVTX 使用内置 windows-evtx 模板解析。
- 已完成实测：System 42,957 条 + Application 34,281 条可正常解析与检索。

### 3.3 SSH 远程

1. 先在“系统设置 → SSH 主机”添加主机（密码或密钥，可配置 ProxyJump）。
2. 选择主机与远程路径（支持通配符）。
3. 策略：
   - `compress`：远端 tar+gzip 拉取（默认）；
   - `filter`：按正则过滤（本地安全过滤）；
   - `journalctl`：拉取 systemd JSON 日志；
   - `incremental`：从上次 offset 使用 `tail -c`；
   - `plain`：SFTP 直接读取。
4. 可先“测试连接”。采集只执行只读命令。
5. 一键采集系统日志：点击“一键采集系统日志”，应用会只读扫描远端 `/var/log` 下的文本日志（排除 btmp/wtmp/journal/压缩轮转等非文本文件），把发现的路径填入远程路径并自动以 `plain` 策略启动采集，混合来源使用自动解析。
6. 远程日志查找：
   - 查找范围可选 `/var/log`、全盘 `/`（较慢，自动跳过 /proc、/sys、容器与系统二进制目录）或自定义目录；
   - 关键词留空时仅列出日志文件；填写关键词后可选择“搜索日志内容”，否则按路径匹配；
   - 可按需包含 `.gz` / `.1` 等轮转压缩日志；
   - 结果可全选/清空并“拉取选中日志”（`plain`，支持 `.gz` 解压）；按内容搜索时可勾选“仅拉取匹配行”使用 `filter` 策略只保留命中行。
7. 端口必须与远端一致：默认 22；如靶场/自定义服务使用 222 等非标准端口，请在“设置 → SSH 主机”编辑该主机的端口后再测试。

### 3.4 文件导入

适用于单个日志/压缩包/EVTX；流程与本地文件一致。

## 4. 日志分析

### 4.1 搜索语法

```
error
error AND timeout
"connection refused"
level:ERROR
host:web-01
fields.status:[400 TO 499]
@timestamp:[2024-01-01T00:00:00Z TO 2024-01-02T00:00:00Z]
(level:ERROR OR level:CRITICAL) NOT debug
error*
```

- 空格 = AND；支持 `AND`/`OR`/`NOT`/括号；
- 字段：`level`、`host`、`source`、`event_id`、`event_type`、`source_ip`、`destination_ip`、`message`、`fields.<key>`；
- IP 字段兼容常见命名：`source_ip` / `src_ip` / `IpAddress` / `SourceIp` / `RemoteIp` / `RemoteAddr` / `ClientIp` 等视为来源 IP；`destination_ip` / `dest_ip` / `DestinationIp` / `DestAddress` / `DstAddr` 等视为目的 IP；
- `event_type` 优先取 `event_type` / `EventType` / Windows `Channel`（Security、System 等），其次 Provider、源文件名与来源；派生字段已建立 bitmap 索引，字段过滤与聚合不再逐条解压日志；
- 结果默认按时间倒序，可在表头切换排序与方向；
- 查询快照可保存/恢复筛选条件。

### 4.2 列表与详情

- 虚拟滚动支持大量日志；滚动到底自动加载下一页。
- 点击行打开详情抽屉：元数据、动态 Fields、原始日志、复制。
- 悬停行右侧的“独立页面”按钮，或在抽屉中点击 **“完整日志”**，进入 **日志详情** 独立页面：
  - 解析结果 JSON（完整 LogEntry，含 event_id/provider/fields/raw_log 等）；
  - 原始日志（采集器读取的原始文本）；
  - 字段表（完整键值）；
  - 右侧显示元数据与相邻日志，支持上一条/下一条、返回日志列表（保留原查询与滚动位置）。
- “上下文”查看前后各 N 条日志并高亮锚点；弹窗顶部可选择 ±5 / ±10 / ±20 / ±50 / ±100 / ±200 条窗口，选择会记住并在下次打开时沿用。
- 列表行悬停可点击 AI 按钮，或在日志详情页点击 **AI 分析**：
  - **仅分析本条**：分析目标日志本身；
  - **上下文综合分析**：自动检索前后 ±5/±10/±20/±50/±100/±200 条日志一并分析；上下文超长时围绕目标日志截取，并提示截断范围；
  - 可填写补充问题；结果显示风险级别、摘要、关键发现、处置建议与相关 DocID。
- Windows 事件日志在列表中直接显示事件 ID（无需打开详情）；行列消息会把 EVTX 的 `System` / `UserData` 结构转换为“通道 / 事件 ID / 提供程序 / 计算机 / 用户”等中文摘要。
- 双击列表行可展开“全部字段”，字段名以中文展示并保留原始键；详情页字段表同样使用中文名称。
- 日志工作台顶部 **AI 分析** 面板支持选择日志类型与时间范围，按“聚合分析”或“逐条分析”调用 AI；聚合分析可选择事件类型、来源 IP、目的 IP、事件 ID、主机、级别作为聚合维度，结果同时展示各维度 Top 20；逐条模式可选择仅分析当前日志或结合上下文，结果按项目保存，重新打开不会自动重跑。
- 可将日志标记为证据（选择已有调查工单或新建），或直接创建调查工单。

### 4.3 图表与聚类

- 时间线（自动选择分钟/小时/天桶）、级别分布、主机 Top。
- “维度聚合”可选择事件类型、来源 IP、目的 IP、事件 ID、主机或级别，按当前查询范围展示 Top 10。
- 模式聚类：泛化 IP/数字/路径/UUID 等为模板，展示次数、占比、示例与参数值。

### 4.4 AI 分析（可选）

需先在“设置 → AI 提供商”配置并启用。支持：

- 异常检测：基于当前筛选结果的采样，返回风险等级、发现与建议；
- 根因分析：返回根因列表与置信度、时间线摘要；
- 自然语言查询：把问题转换为查询条件并应用；
- 报告生成：Markdown 报告，可复制或写入文件；报告范围可独立选择时间范围、日志类型、来源 IP、目的 IP、事件 ID 与聚合维度，条数仅作为 AI 采样上限；
- 调查工单 AI 分析：生成时间线、攻击阶段、发现与处置建议。

> 发送给 AI 的日志量受设置限制；使用本地 Ollama 时数据不出本机。

## 5. 调查工单

1. 新建工单：标题、描述、线索（IP/用户/PID/文件/域名/事件 ID/日志条目）、可选时间范围、可选关联 DocID、标签、风险分与处理人。
2. 标记证据：
   - 在日志页/日志详情中“标记为证据”；
   - 在工单“证据链”中按 DocID 直接添加证据与备注；
   - 在“关联日志”面板把线索命中的日志一键标记为证据。
3. 工单详情查看：
   - **证据链**：证据日志、备注、标记时间，可查看完整日志或取消标记；
   - **关联日志**：证据优先，其次按线索值检索（最多 200 条），可打开日志或标记为证据；
   - **调查时间线**：证据/线索命中的日志按时间升序展示，DocID 可点击打开；
   - **AI 研判**：AI 时间线中的 DocID 同样可点击打开。
4. 编辑工单：可修改标题、描述、线索类型/值、时间范围、状态、风险分、处理人与标签；清空风险分或时间范围会显式移除对应字段。
5. “AI 分析”生成研判结论；“导出证据包”生成 ZIP，包含 manifest.json（SHA256）、investigation.json、evidence.json、timeline.json、logs.jsonl（关联日志 JSONL）与 README.txt。
6. 支持删除工单（不可恢复，证据标记与 AI 研判一并删除，但不删除原始日志）；结案后仍保留只读记录。

## 6. 威胁狩猎

威胁狩猎不再内置检测规则与 IOC 指标库，检测统一由 AI 完成。

### 6.1 检测结果

- 选择时间范围（近 15 分钟 / 1 小时 / 24 小时 / 7 天 / 全部或自定义）、AI 提供商与最大日志数，点击“开始检测”。
- 结果显示风险级别、研判摘要、关键发现、处置建议与异常条目；点击异常条目的 DocID 可打开日志详情。
- 检测结果按项目保存在浏览器本地；关闭页面或切换项目后再次打开不会自动重新检测，只有点击“开始检测”才会重新调用 AI。

### 6.2 网络连接

- 展示当前主机监听端口、全部/外联连接状态、进程与外联 IP；绑定 `0.0.0.0` / `::` 的端口标记为“暴露”。
- 打开“实时刷新”后每 5 秒自动更新；也可手动刷新。

### 6.3 取证包

- 范围：调查工单 / 当前查询 / 指定 DocID。
- 输出 ZIP 包含 manifest.json（SHA256）、调查工单与证据、命中日志 JSONL、README。
- 结果展示路径、大小与 SHA256，可在文件管理器中显示。

## 7. 设置

- **通用**：并发、索引、解析、UI 参数；部分需重启生效。
- **AI**：OpenAI / DeepSeek / Ollama / 自定义兼容接口；支持识别模型列表、勾选要使用的模型、在保存前测试模型连通性；密钥加密存储，编辑时留空保持原密钥。
- **SSH**：主机 CRUD、认证方式、ProxyJump、测试连接。
- **解析模板**：查看/编辑/复制模板，正则与字段映射校验，样本预览；支持 AI 生成模板。

## 8. 常见问题

| 问题 | 排查 |
|---|---|
| 无法读取 Security.evtx | 以管理员身份运行；确认文件未被占用 |
| 搜索无结果 | 检查查询语法、时间范围、索引是否构建完成；重新打开项目可触发索引加载 |
| 采集速度慢 | 降低并发、检查磁盘；SSH 可切换 compress/zstd |
| SSH 连接被拒绝（actively refused） | 主机可达但对应端口没有 sshd 监听或被防火墙拒绝；确认实际端口（靶场常用 222），在“设置 → SSH 主机”修改端口后重测 |
| SSH 远程日志查找无结果/报错 | 确认远端为 GNU/Linux 工具链（find `-printf`/`-readable`、grep `-Z`）；非 root 用户无法读取 secure/audit 等文件；可缩小目录或去掉“搜索日志内容”重试 |
| AI 请求失败 | 设置中测试连接；检查 endpoint/model/API Key；Ollama 确认服务已启动 |
| 导入项目失败 | 确认是 `.glogpkg.zip` 且 manifest 完整；同名项目 ID 需先删除旧项目 |
| 删除项目失败，提示 `logs.dat` 被占用 | 关闭其它 GLog 实例或正在运行的采集任务后重试；数据库记录会保留，不会产生半删除状态 |
| 数据丢失 | 检查 `secrets.key` 是否保留；项目目录是否被移动 |

## 9. 快捷键

- `Esc`：关闭弹窗/抽屉；
- 搜索框 `Enter`：执行查询；
- 日志列表支持滚动加载（不强制分页）。
