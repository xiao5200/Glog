## 2. 派生字段 bitmap 索引

- 新增共享包 `internal/logfields`：统一提取 `event_type`、`source_ip`、`destination_ip`，索引构建与查询/聚合共用同一套别名与回退规则，避免两套规则漂移。
- `event_type` 优先级：`event_type`/`EventType` → Windows `Channel` → `Provider` → 源文件名（basename）→ 来源。
- IP 别名扩充：来源侧兼容 `source_ip` / `src_ip` / `SourceIp` / `IpAddress` / `RemoteIp` / `RemoteAddr` / `ClientIp` / `ClientAddr` / `SrcAddr` 等；目的侧兼容 `destination_ip` / `dest_ip` / `dst_ip` / `DestinationIp` / `DestAddress` / `DstAddr` / `TargetIp` 等；空值与 `-` 视为缺失。
- EVTX 采集新增顶层 `channel` 字段（`/Event/System/Channel`），parser 自动放入 `Fields`。
- `bitmap.idx` 使用独立的 `bitmapFormatVersion = 2`；索引字段新增 `event_type` / `source_ip` / `destination_ip`。打开旧项目时版本校验失败会从 `raw/logs.dat` 整库重建，自动补齐历史日志的派生字段。
- 查询侧：
  - 结构化过滤 `FieldFilter` 支持三个派生字段的 `eq/in/ne/not_in`，`field:value` 文本语法支持等值与前缀通配；
  - 日志聚合与 AI 聚合统计优先走 bitmap 计数；
  - 新增 `Store.FieldCounts(field, filter)`，直接对内部 roaring 位图求交集基数，避免高基数字段逐值复制 docID 数组。
- 兼容性：`internal/query/fields.go` 保留原有函数签名并委托 `logfields`，查询语义不变。

## 4. SSH 一键采集与远程日志检索

### 后端

- 新增 `App.SearchSSHLogs`（Wails 绑定）与 `internal/collector/ssh_search.go`：
  - 扫描 `/var/log`、全盘 `/`（`-xdev` + prune `/proc`、`/sys`、容器与系统目录）或自定义绝对目录；
  - 仅返回常规、可读的日志类文件；排除 btmp/wtmp/lastlog、journal、pcap、数据库、压缩归档，以及 Debian/Ubuntu installer 的 `.dat`、`hardware-summary`、`status` 等非日志数据；
  - `search_content=true` 时用 `find -print0 | xargs -0 grep -I -l -F -Z` 做固定字符串内容检索，再用同一 SSH 连接通过 SFTP 补全 size/mtime；
  - 文件名检索按全路径字面子串匹配；默认不含 `.gz` / `.1` 等轮转文件，可按需包含；
  - NUL 分隔输出，保留路径中的空格与制表符；默认 200 条，上限 2000，达到上限提前终止远端命令；
  - 参数全部经 `shellQuote` / `validateRemotePath` 校验；根目录必须为绝对路径；只执行只读命令；
  - 普通扫描 2 分钟、全盘扫描 5 分钟超时；部分文件无权限但已有结果时忽略非零退出。
- 抽出 `sshOptionsFromHost` 复用主机读取/解密逻辑，`StartSSHCollection` 与 `TestSSHConnection` 行为不变。
- `runSSHStreamDetailed` 额外返回 stderr 文本，搜索错误信息更明确。

### 前端

- SSH 采集页新增：
  - **一键采集系统日志**：只读扫描 `/var/log` 文本日志（最多 300 个），自动填入路径并以 `plain` 策略立即采集；混合来源使用自动解析；
  - **远程日志查找**：范围选择 `/var/log`、全盘 `/`、自定义目录；关键词留空只列文件，填写后可勾选“搜索日志内容”；可选包含轮转/压缩日志；
  - 结果列表支持全选/清空、显示大小与修改时间，可“拉取选中日志”（`plain`，支持 `.gz`）；按内容搜索时可“仅拉取匹配行”（`filter` 策略，关键词转义为字面量正则）；
  - 切换主机或重新查找会清空旧结果与选择。

## 6. 使用提示与已知边界

1. 旧项目首次打开会因 bitmap v2 自动重建一次索引；日志量大时首次打开变慢属预期。
2. 远程检索依赖远端 GNU findutils（`-printf` / `-readable`）、GNU grep（`-Z`）与 `xargs -0`；BusyBox 等精简系统可能不支持，会返回远端 stderr 错误。
3. 全盘检索受 `-xdev` 限制只扫描根文件系统；其他挂载点请用自定义目录检索。
4. 内容检索为固定字符串（`grep -F`），不支持正则；按路径检索支持关键词子串。
5. SSH 沿用项目既有策略，不校验 known_hosts。
6. 检索结果按修改时间降序；达到上限时取遍历顺序前 N 条再排序，不保证全局最新 N 条。
7. `Security.evtx` 仍需管理员权限；备份/迁移不要遗漏 `build\bin\data\secrets.key`。
